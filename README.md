# Blinkit Sales Analysis Dashboard | Power BI

## Overview

This project analyzes Blinkit's sales performance, outlet distribution, and product categories using Power BI.

---

## Key Metrics

- Total Sales: $1M+
- Number of Items: 9K+
- Average Sales: $141
- Average Rating: 3.92

---

## Key Insights

- Supermarket Type1 drives highest sales
- Tier 3 outlets contribute most revenue
- Fruits & Vegetables and Snacks are top-selling categories
- Low Fat items dominate overall sales
- Sales peaked around 2018 based on outlet establishment trends

---

## 🚀 Business Impact

This dashboard helps understand product demand, outlet performance, and sales trends for better decision-making.
